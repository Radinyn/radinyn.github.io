How the output is produced

  1. Read the intensity. For every pixel take the largest of its red, green and blue values. These slides are single-channel fluorescence, so this is the signal channel.
  2. Smooth. Blur the intensities with a separable Gaussian of the chosen kernel size σ (mirror padding at the edges); σ = 0 skips this step.
  3. Total the intensity. Add up all pixel values of the blurred image. This total is the mass.
  4. Pick the threshold. Walk the pixel values from brightest to dimmest, accumulating them, until the running sum reaches the chosen share of the mass (50% by default). The value you stopped on is the threshold.
  5. Apply the mask. A pixel is kept when its blurred value reaches the threshold, and it is written out with its original intensity. Removed pixels become 0 (black).
  6. Write the file. The result is saved as an 8-bit grayscale PNG at the source resolution, with the original intensity scale preserved.
